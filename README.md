# OMKARA RESOURCES

Official website of **OMKARA RESOURCES**.

*Building People | Building Structures | Building Futures*

## Overview

OMKARA RESOURCES is a multi-division business offering:

- **Manpower Supplies**: staffing and workforce solutions
- **Civil Constructions**: construction and infrastructure services
- **IT Services**: software, web and technology solutions

The website has four pages: Home, Services, About Us and Contact Us. It supports Light and Dark mode and works on desktop, tablet and mobile.

## Built With

React, Vite, Tailwind CSS and React Router.
